# Data Mining, Modelling and Analytics — Assignment 2

This repository contains two machine learning projects developed using Python and Jupyter Notebook.

## Project 1: Wholesale Customer Segmentation
Applied unsupervised learning to segment 440 wholesale customers based on purchasing behaviour.

**Algorithms:** K-Means, Hierarchical Clustering, and DBSCAN.

**Key Finding:** K-Means identified two customer segments with distinct spending patterns, supporting targeted marketing and distribution strategies.

## Project 2: Credit Card Fraud Detection
Applied anomaly detection and classification techniques to identify suspicious transactions from 284,807 credit card transactions.

**Algorithms:** Statistical Z-score, MiniBatch K-Means, and Random Forest.

**Key Finding:** Random Forest achieved an Average Precision of 0.8733 and identified 90% of fraudulent transactions among the top 100 ranked transactions.

## Tools and Libraries
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, and Jupyter Notebook.
